# 文本投递格式

preview_delivery 是静态来源规则下的首个安全 CSV 成员预览，不负责整包接收和规则确认。
ZIP 成员以中央目录中的 ordinal 定位，同名成员可能出现；name 是展示路径而不是可靠主键。
接收限制需同时考虑单成员、成员总和与实际读出的字节，压缩大小不等于展开大小。
east 已确认规则为 UTF-8 BOM 可选、逗号分隔；west 当前为 GB18030、分号分隔。来源资料可能与新投递不符。
样本字段 member_id 必须保留原文本，amount 的逗号是金额内容，不是无条件的字段边界。
physical_line_end 是 csv.reader 已消耗的物理行数，不是字节范围；多行字段仍只有一个逻辑 record。
intake_sink 消费明确解释后的文本字段，并区分缺少值的拒收记录。未知列不能无声删除。
原 ZIP 字节与成员字节、来源规则版本、人工确认分别保存，规则修订不改变原件。
